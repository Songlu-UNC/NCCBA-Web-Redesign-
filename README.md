# NCCBA Website Redesign Prototype

A React and TypeScript visual prototype for reworking the North Carolina Chinese Business
Association website without WordPress.

## Run Locally

```bash
npm install
npm run dev
```

The prototype keeps the original site structure while giving the interface a cleaner association
homepage, event, membership, sponsor, account, and contact experience. Existing image assets are
loaded from the `Img/` folder.
